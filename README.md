# 🏋️ Vireon Fit

Vireon Fit is a gamified fitness platform designed to help individuals and gyms create, manage, and track structured workout routines with progression and performance tracking.

## 🚀 Vision

Turn training progression into a measurable journey.

Vireon Fit combines:
- Structured workout planning
- Performance tracking
- Gamification (XP, levels, progression)
- Multi-tenant gym management
- White-label gym customization

---

## 🧠 Core Features (MVP)

### 👤 Individual Users
- Personalized routine generation
- Workout tracking (sets, reps, weight)
- XP system & levels
- Weekly challenges
- Progress history

### 🏢 Gym Mode (Multi-tenant)
- Gym branding (logo, colors)
- Roles: Admin, Coach, Member
- Assign routines to members
- Manage workout templates
